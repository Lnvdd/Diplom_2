# Diplom_2
 
Автотесты для stellarburgers — проекты содержат автоматизированные методы для учебного API сервиса stellarburgers

Установите зависимости: pip install -r requirements.txt 

Запустите тесты: pytest -v --alluredir=allure-results 

Генерация отчёта Allure: allure serve allure-results

Открыть отчет в браузере: allure open allure-report
